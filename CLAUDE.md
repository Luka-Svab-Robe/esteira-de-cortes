# Esteira Canal Dark — instruções para o Claude Code

Este projeto é operado por você a partir de pedidos em linguagem natural do usuário.
O manual completo (cenários, comandos, regras e solução de problemas) está em AGENTS.md:

@AGENTS.md

Lembretes rápidos:
- Responda sempre em português do Brasil; o usuário não digita comandos — você executa.
- Comece cada sessão com `python esteira.py diagnostico --rapido`.
- Sem chave de LLM no `.env`, produza com `--modo-agente` e escreva você mesmo o roteiro.
- Nunca aprove/publique sem o usuário pedir explicitamente ou aprovar no painel.
